# دورك — إدارة الانتظار بالـ QR

مشروع عربي باستخدام Laravel 13 وFilament 5 وMySQL، مع Firestore للتحديث اللحظي وFCM لإشعارات الموبايل.

- [فكرة المشروع والتصميم](PROJECT_OVERVIEW.md)
- [مهام التنفيذ والمتابعة](TASKS.md)
- [التشغيل وحسابات التجربة وحدود النسخة](RUNNING.md)
- [إنشاء Firebase وربطه](FIREBASE_SETUP.md)
- [النشر والتشغيل والاستعادة](DEPLOYMENT.md)

النسخة المحلية تشمل الحجز والمتابعة، وشاشة الموظف والعرض، وإدارة الحسابات والصلاحيات والشبابيك، والورديات، وسجل التذاكر وفلاترها وإحصائيات الموظفين وأوقات الذروة. أوامر الاستقبال محمية من إعادة الإرسال وتغيير تذكرة عميل جديد بطلب قديم. توجد لوحة تشغيل ونسخ احتياطي وسياسة احتفاظ لمدة سنة.

آخر تحقق: 118 اختبارًا ناجحًا، واختبار تزامن MySQL، وتجربة Chrome لدورة العميل وصلاحيات الموظف والعرض والتقارير وصفحة الموبايل. بناء الواجهة وService Worker ناجح. الربط بحساب Firebase الحقيقي والإشعارات الفعلية لم يختبرا بعد.

## التشغيل المحلي

```powershell
composer install
php artisan migrate
php artisan filament:assets
npm.cmd install
npm.cmd run build
php -d auto_prepend_file= artisan serve --host=127.0.0.1 --port=8000
```

شغّل العامل والجدولة في نافذتين منفصلتين: `php artisan queue:work` و`php artisan schedule:work`.

افتح العملاء على `http://127.0.0.1:8000` والإدارة على `http://127.0.0.1:8000/admin`.

حسابات التجربة وكلمات مرورها العشوائية محفوظة محليًا في `storage/app/private/demo-access.md`، وهو ملف خاص مستثنى من Git. عند عدم وجودها، شغّل `php artisan db:seed --class=DemoSeeder` في البيئة المحلية فقط. لا تنشر حسابات التجربة على الإنترنت.

راجع RUNNING.md قبل النشر. Firebase غير مفعّل إلى أن تضيف إعدادات حسابك، وتعتمد صفحات المتابعة على تحديث Firestore المباشر فقط بدون تحديث دوري من الخادم. لا تحتوي ملفات المستودع على مفتاح حساب الخدمة.

الإضافات الحالية: شاشة عامة للفرع، وتنبيه اقتراب الدور، وتقدير انتظار من بيانات فعلية، وتقييم وتقارير رضا العملاء والخدمات. يدير مسؤول النظام مواعيد العمل الأسبوعية لكل فرع (وقت بداية ونهاية لكل يوم مع إمكانية الإغلاق)، وتظهر هذه المواعيد للعملاء في صفحة الفرع والحجوزات والشاشة العامة، ويُمنع الحجز خارجها. ويحجز العميل أونلاين ثم يؤكد حضوره؛ تبدأ أولوية الموعد عند وقته مع أول شباك مناسب يفضى.
